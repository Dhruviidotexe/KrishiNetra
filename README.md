# KrishiNetra

KrishiNetra is an oilseed marketplace platform developed as a solution for a **Smart India Hackathon (SIH) problem statement 2024**.

The platform is designed to connect Indian farmers, processors, exporters, and buyers through a single digital marketplace. It helps users discover oilseed products, monitor market prices, view price trends, and manage orders through a simple and user-friendly interface.

## Features

* Farmer, Processor, and Buyer/Exporter login
* Digital oilseed marketplace
* Oilseed price trends and predictions
* Products including soybean, groundnut, mustard, and sunflower
* Order tracking
* User profiles
* Interactive market charts
* Responsive interface

## Tech Stack

* React.js
* TypeScript
* Vite
* Tailwind CSS
* Recharts
* Lucide React

## Getting Started

```bash
git clone <repository-url>
cd KrishiNetra
npm install
npm run dev
```

Open the local development URL shown in the terminal.

## Objective

KrishiNetra aims to provide a transparent and accessible digital marketplace for India's oilseed ecosystem, helping farmers and buyers discover products, understand market trends, and manage transactions efficiently.

## Hackathon

**Smart India Hackathon (SIH)**
Developed as a solution to a Smart India Hackathon problem statement focused on improving the oilseed marketplace and agricultural ecosystem through technology.
